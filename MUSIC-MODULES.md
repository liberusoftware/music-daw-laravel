# Music module repositories

Status: under development. Projects core, Media Library core and their optional APIs are installed from modules/ and synchronized to separate repositories. APIs are disabled by default. Projects provides metadata, conditional checkpoint/recovery/import commands and scoped revision polling. Media Library API provides conditional metadata, resumable intake and queued verification/restoration/waveform jobs and short-lived authenticated download URLs; pack/pin/lifecycle HTTP workflows remain unfinished. The optional Projects Livewire workspace now provides session and track metadata editing, checkpoints/autosaves, reviewed recovery/import, paginated history and explicit draft backups. It is disabled by default; browser operational and accessibility verification remains outstanding. Other Music packages remain planned. Track acceptance and remaining work in the [delivery roadmap](https://github.com/liberusoftware/project-music-daw-laravel-filament/issues/94); no complete DAW release is claimed.
